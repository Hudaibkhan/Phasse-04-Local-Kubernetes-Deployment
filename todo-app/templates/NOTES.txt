Evolution Todo has been deployed to Minikube!

{{- if .Values.backend.enabled }}

Backend Service:
  Type: {{ .Values.backend.service.type }}
  Port: {{ .Values.backend.service.port }}

  To access the backend API:
  kubectl port-forward svc/{{ include "todo-app.fullname" . }}-backend {{ .Values.backend.service.port }}:{{ .Values.backend.service.port }}

  Then visit: http://localhost:{{ .Values.backend.service.port }}/api/health
{{- end }}

{{- if .Values.frontend.enabled }}

Frontend Service:
  Type: {{ .Values.frontend.service.type }}
  Port: {{ .Values.frontend.service.port }}

  To access the frontend application:
  minikube service {{ include "todo-app.fullname" . }}-frontend --url

  Or use port-forwarding:
  kubectl port-forward svc/{{ include "todo-app.fullname" . }}-frontend {{ .Values.frontend.service.port }}:{{ .Values.frontend.service.port }}

  Then visit: http://localhost:{{ .Values.frontend.service.port }}
{{- end }}

To check the status of your deployment:
  kubectl get pods -l "app.kubernetes.io/instance={{ .Release.Name }}"
  kubectl get services -l "app.kubernetes.io/instance={{ .Release.Name }}"

To view logs:
{{- if .Values.backend.enabled }}
  kubectl logs -l "app.kubernetes.io/name=backend" -f
{{- end }}
{{- if .Values.frontend.enabled }}
  kubectl logs -l "app.kubernetes.io/name=frontend" -f
{{- end }}
